# Карточка тестера (песочница, MVP)

Дата актуализации: 2026-10-29

## 1) Контур тестирования

- Среда: песочница (sandbox-first).
- Срок доступа: 1–2 недели.
- После завершения окна: песочница закрывается.

## 2) Доступ

- URL стенда: `http://localhost:3010`
- Админ:
  - Логин: `admin@fitclub.local`
  - Пароль: `11111`
- Клиент:
  - Логин: `ivan.smirnov@fitclub.local`
  - Пароль: `11111`

## 3) Что обязательно проверить

1. Публичная часть
   - Главная страница открывается.
   - Форма лид-магнита отправляется.
   - Открываются `/offers`, `/trainers`, `/schedule`.

2. Клиентский контур
   - Вход клиента.
   - Профиль сохраняется.
   - Запись на занятие и отмена по правилам.
   - Чат: режимы `AI-консультант`, `AI-тренер`, `Позвать администратора`.
   - Память AI: создать, изменить, удалить запись.

3. Админский контур
   - Вход администратора.
   - Очередь обращений и ответы.
   - Настройки AI/клуба сохраняются.

4. Безопасность/изоляция
   - Клиент не может выполнять действия админа.
   - Клиент не может управлять чужими данными.

## 4) Куда заводить дефекты

Формат дефекта:

- Приоритет: `Критичный / Высокий / Средний / Низкий`
- Страница/раздел
- Шаги воспроизведения
- Ожидаемый результат
- Фактический результат
- Подтверждение (скрин, URL, текст ошибки)

## 5) Известные ограничения MVP

- Отсутствуют реальные платежи/CRM/турникеты.
- Push/SMS/email-рассылки не реализованы.
- При отсутствии `AI_API_KEY` работает fallback-режим AI.
- Контур временный, данные в песочнице не считаются production-данными.

## 6) Быстрый reset стенда (для команды)

```bash
npm install
npm run build
node dist/src/db/seed.js
node dist/src/server.js
```

Или одной командой (PowerShell):

```powershell
./scripts/sandbox-reset.ps1
```
