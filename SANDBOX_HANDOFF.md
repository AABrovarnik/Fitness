```powershell
./scripts/sandbox-smoke.ps1
```

### Полный reset + smoke

```powershell
./scripts/sandbox-reset.ps1
```

## 4) Чек-лист передачи (Day 1)

- [ ] `preflight` = PASS
- [ ] `smoke` = PASS
- [ ] Рабочие логины подтверждены
- [ ] Публичные страницы открываются
- [ ] Клиентский и админский контуры открываются
- [ ] Базовый прогон занесён в `SANDBOX_RUN_LOG.md`

## 5) Чек-лист сопровождения (Day 2+)

- [ ] После каждого фикса запускать `smoke`
- [ ] Любой инцидент фиксировать в журнале прогонов
- [ ] Держать freeze-scope: без новых фич, только исправления
- [ ] В конце окна сформировать итоговый отчёт

## 6) SLA на окно 1–2 недели

- Критичный дефект: реакция до 2 часов, hotfix в приоритете.
- Высокий: реакция до 4 часов, fix в ближайшем релиз-цикле.
- Средний: планирование в рамках текущей недели.
- Низкий: фиксация в backlog и перенос по согласованию.

## 7) Канал дефектов

Каждый дефект фиксировать в формате:

- Приоритет
- Где найдено
- Шаги воспроизведения
- Ожидаемый результат
- Фактический результат
- Подтверждение (скрин/лог/URL)

## 8) Условия закрытия песочницы

По завершении окна:

1. Финальный smoke и приёмочный прогон.
2. Обновление `SANDBOX_RUN_LOG.md` итоговой записью.
3. Снятие списка задач на production-этап.
4. Остановка и закрытие песочницы.
