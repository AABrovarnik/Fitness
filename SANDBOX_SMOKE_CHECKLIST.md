# Smoke-чеклист песочницы (обязательный минимум)

Дата: 2026-10-29

Использовать перед передачей стенда тестеру и после каждого значимого фикса.

Быстрый автопрогон (PowerShell):

```powershell
./scripts/sandbox-smoke.ps1
```

Для нестандартного адреса:

```powershell
./scripts/sandbox-smoke.ps1 -BaseUrl "http://localhost:3010"
```

## A. Доступность стенда

- [ ] `GET /health` возвращает `{"ok":true}`
- [ ] `GET /` открывается без ошибок
- [ ] `GET /offers` открывается
- [ ] `GET /trainers` открывается
- [ ] `GET /schedule` открывается

## B. Публичный путь

- [ ] Форма лид-магнита отправляется успешно
- [ ] Лид появляется в админской очереди
- [ ] Публичный AI-чат отвечает и даёт следующий шаг

## C. Клиентский путь

- [ ] Вход клиентом проходит
- [ ] Профиль клиента сохраняется
- [ ] Создание брони работает при доступном слоте
- [ ] Конфликт вместимости корректно блокирует вторую запись
- [ ] Отмена брони работает по правилу времени
- [ ] Чат клиента работает в режимах `ai/trainer/human`

## D. Память AI

- [ ] Создание записи памяти
- [ ] Редактирование записи памяти
- [ ] Удаление записи памяти
- [ ] Нет доступа к памяти другого клиента

## E. Админский путь

- [ ] Вход админом проходит
- [ ] Список клиентов/лидов/обращений открывается
- [ ] Ответ админа в обращении сохраняется
- [ ] Изменения в настройках AI сохраняются

## F. Безопасность

- [ ] Клиент не может открыть админ-маршруты
- [ ] Изменяющие запросы без CSRF отклоняются

## G. Техническая отметка прогона

- Дата/время прогона:
- Commit (short hash):
- Ответственный:
- Итог: `PASS / FAIL`
- Комментарии/риски:
